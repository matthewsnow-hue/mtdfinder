About

Built by a sole trader, for sole traders

MTD Finder is run by Matthew Snow trading as Sno Automations, a UK sole trader.

We built MTD Finder because HMRC's official list is accurate but hard to browse, and many "best MTD software" articles are written by vendors ranking their own products.

How we work

  • Every tax claim links to HMRC or GOV.UK.
  • Software data comes from HMRC's software finder and is rechecked regularly. Last checked: 2026-10-14.
  • The main list is alphabetical. Sponsored slots are labelled.
  • We're independent and not affiliated with HMRC.
